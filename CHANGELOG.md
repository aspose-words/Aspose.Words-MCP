# Changelog

All notable changes to this project will be documented in this file.

The format is based on "Keep a Changelog", and versioning adheres to Semantic Versioning (SemVer).

## [26.4.0] - 2026-04-30
### Added
- No new MCP tools added. All 55 release note items are bug fixes and rendering improvements in the upstream Aspose.Words library that automatically benefit the server.

### Changed
- Aligned server versioning with Aspose.Words 26.4.0.

### Skipped
- PDF Export: Node.CustomNodeId in PDF logical structure (major feature) — behind-the-scenes rendering improvement; no new MCP-exposable API.
- Charts: Funnel chart data labels rendering (major feature) — rendering improvement for chart visualization; server has no chart-specific tools.
- Charts: Leader line chart style settings (major feature) — rendering improvement for chart visualization; server has no chart-specific tools.
- Charts: Locale IDs for default axis titles (major feature) — rendering improvement for chart visualization; server has no chart-specific tools.
- Detailed error information upon building reports (issue 1) — LINQ Reporting Engine is not exposed through MCP server tools.
- LINQ Reporting Engine exception with outer lambda parameter (issue 7) — LINQ Reporting Engine is not exposed through MCP server tools.
- LINQ Reporting Engine NullReferenceException (issue 50) — LINQ Reporting Engine is not exposed through MCP server tools.
- LINQ Reporting Engine InvalidOperationException with field delimiters (issue 52) — LINQ Reporting Engine is not exposed through MCP server tools.
- JsonDataSource large integer exception (issue 53) — LINQ Reporting Engine data sources are not exposed through MCP server tools.
- CompareOptions.IgnoreTables unexpected behavior (issue 23) — document comparison is not exposed through MCP server tools.
- CheckBox form fields lost after loading ODT (issue 27) — form field manipulation is not exposed through MCP server tools.
- ParentNode access for style revision upon ODT/OTT conversion (issue 29) — internal revision API not exposed through MCP server tools.
- InvalidOperationException with ShowInBalloons.FormatAndDelete (issue 30) — revision rendering balloons not exposed through MCP server tools.
- Incorrect default axis title names for Korean, German, Portugal, Italian, Spain cultures (issue 35) — chart rendering improvement; server has no chart-specific tools.
- Expand textboxes generated by PDF reader to XLSX cells (issue 39) — XLSX export is not exposed through MCP server tools.

## [26.3.0] - 2026-04-04
### Added
- Exposed opt-in run joining through the existing text replacement MCP surface.

### Changed
- Aligned server versioning with Aspose.Words 26.3.0.

### Skipped
- `OpenAiModel(name)` / `OpenAiModel(name, api_key)` were not exposed because this MCP server has no AI tool surface, and exposing them would require new secret/configuration infrastructure.
- `TableStyle.bidi` removal has no server-visible impact because this API is not used in this repository and is not exposed through MCP tools.

## [25.11.0] - 2025-12-02
### Added
- Initial version of the MCP server for Aspose.Words automation (based on FastMCP).
- Integration with Aspose.Words 25.11.0.
- Core capabilities: content creation and editing, tables, styles, comments and footnotes, watermarks, links, layout/formatting, export, and file read/write.
- Server startup via the `aspose-words-mcp` script.
- Configuration via environment variables (`.env`).
